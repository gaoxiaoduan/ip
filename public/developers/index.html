IP 出口检测（ip.33338888.xyz）开发者资源

这些资源帮助 API 客户端和 AI agent 读取当前请求的公网出口观测，或通过 MCP 在对话中调用交互式工具。

HTTP API

  • OpenAPI 规范：无需认证的 GET /api/observe。
  • API endpoint：读取当前请求的公网 IP、国家/地区、城市、网络组织、ASN 和边缘机房。

MCP Server

  • Streamable HTTP MCP endpoint。
  • MCP manifest：连接信息与工具描述。
  • MCP server card：能力和资源卡片。
  • 工具：observe_ip；交互式 MCP App 资源： ui://ip-exit-observer/observe.html。

Agent guidance

需要判断当前请求的公网出口、国家/地区、城市或网络组织时使用 IP 出口检测；不要把一次观测当作精确定位、所有流量路径或代理配置诊断。
