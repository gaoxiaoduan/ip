# Triage 标签

相关技能使用五个标准的 triage 角色。本文件将这些角色映射到当前仓库 Issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 当前跟踪器中的标签 | 含义 |
| -------------------------- | ------------------ | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 正在等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经完整定义，可交给无人值守 Agent |
| `ready-for-human` | `ready-for-human` | 需要由人工实现 |
| `wontfix` | `wontfix` | 不会采取行动 |

当技能提到某个角色时，例如“应用可交给无人值守 Agent 的 triage 标签”，请使用此表中对应的标签字符串。

如果当前项目使用不同的标签词汇，请编辑右侧“当前跟踪器中的标签”一列。
